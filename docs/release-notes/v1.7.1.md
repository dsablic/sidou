# SIDOU 1.7.1: newer FM-1s save and update

FM-1s sold since late 2026, mostly on AliExpress, carry a different flash chip: a UC25HQ80
instead of the Puya P25Q80. It is the same size and takes the same commands, but SIDOU 1.7.0
and earlier accepted only the Puya. On a newer unit nothing was saved (songs, LAB sounds and
settings lasted until power-off), and an update from SIDOU was refused. 1.7.1 accepts both.
Nothing else changed.

If you have a newer FM-1 running an earlier SIDOU, install 1.7.1 the usual way. If the update
from SIDOU is refused, hold OCT- at power-on for the rescue and install from there.

Thanks to The Firmware Hub for the report
([Felucca#320](https://github.com/hugelton/Felucca/issues/320)).

**Tested** (2026-11-07): in fm1-emu, a save and an update's first step on both flash chips;
on a real FM-1 with the Puya chip, TESTED-PENDING. No unit with the newer chip was at hand.

The full list is in [CHANGELOG.md](https://github.com/dsablic/sidou/blob/main/CHANGELOG.md).

## Install

Over USB, at your own risk; the official firmware is one install away. Use Felucca's installer:
`fm1_install.py sidou-1.7.1.fwsc`, from the stock firmware, a Felucca-family firmware or an
earlier SIDOU (it finds the FM-1 as "SIDOU FM-1"). Back to stock: install M-VAVE's `FM-1.fwsc`
the same way. Holding OCT- at power-on is a rescue.

**sidou-1.7.1.fwsc**, identity FM-1_964, SHA-256 `SHA-PENDING`.
