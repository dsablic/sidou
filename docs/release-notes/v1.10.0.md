# SIDOU 1.10.0: songs as text, and the USER sounds read back

**Try it in your browser first:** <https://dsablic.github.io/sidou/>, the
[cheat sheet](https://dsablic.github.io/sidou/cheatsheet.html) and the
[how-to videos](https://dsablic.github.io/sidou/videos.html), with a new *What's new in 1.10*.

## On the computer and on the site

- **Whole songs as text (`sidou-song/1`).** A model or a coding agent writes a whole song:
  sections of step-grid strings (a note, a hold, a rest, accent and slide, drum letters on the
  kit), patches as its instruments, a BPM and a play order. The Library page previews it, sends
  it to the FM-1 or opens it in the editor; a `#song=` link shares it; `sidou-sysex song` writes
  the `.sng`. It plays at the nearest of the FM-1's tempos, and the page says which ("asked 120,
  plays 115.7"). The instructions for models are in
  [llms-song.txt](https://dsablic.github.io/sidou/llms-song.txt).
- **The USER sounds read back.** The Library page's USER sounds button lists the sixteen sounds
  LAB kept on your FM-1 and opens each as a patch: listen, share its link, edit it as text, or
  put it into a bank or a song. `sidou-sysex user-sounds` saves each as a `.json` patch. Read
  only: nothing over USB changes the sounds you kept.

## On the FM-1

- SysEx's GET reads the USER sounds' file (16 bytes of flash); DIR still never lists it, and PUT
  and DEL still refuse it. Nothing else changes: sounds, songs and settings from 1.9 load
  unchanged.

## Measured

The image is 577,152 bytes, 2,364 under its ceiling of 579,516. The site's patch module is
83,921 bytes of its 88 KiB.

**Tested on a real FM-1** (2026-11-14, hardware-test.md section 36), with this package: an install
over 1.9.0 with the songs, settings and USER sounds kept; the USER sounds read back with
`sidou-sysex user-sounds`, one opened on the Library page sounding as on the FM-1; and a song
written as text, sent with `sidou-sysex send`, loaded and played in TRACKER.

The full list is in [CHANGELOG.md](https://github.com/dsablic/sidou/blob/main/CHANGELOG.md).

## Install

Over USB, at your own risk; the official firmware is one install away. Use Felucca's installer:
`fm1_install.py sidou-1.10.0.fwsc`, from the stock firmware, a Felucca-family firmware or an
earlier SIDOU (it finds the FM-1 as "SIDOU FM-1"). Back to stock: install M-VAVE's `FM-1.fwsc`
the same way. Holding OCT- at power-on is a rescue.

**sidou-1.10.0.fwsc**, identity FM-1_964, SHA-256 `5b04432900e1d98444341801d4ec37cc4d708b774e1b4bbfc71faeae9c5cf3c0`.
