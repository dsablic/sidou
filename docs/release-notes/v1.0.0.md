# SIDOU 1.0.0: shape one sound and keep it

**Try it in your browser first:** <https://dsablic.github.io/sidou/>, the
[cheat sheet](https://dsablic.github.io/sidou/cheatsheet.html) and the
[how-to videos](https://dsablic.github.io/sidou/videos.html) ("Shape a sound in LAB", "Play a
.sid" and "What's new in 1.0" are new).

## New

- **LAB.** A view for experimenting on the go: five pages (OSC, ENVELOPE, FILTER, MOD, FX), each
  with a drawing of what its four knobs do, from the pulse's width to the filter's curve and the
  effect chain. ENV, LFO and FX on LIVE open it at their page; SELECT turns the pages; ALGORITHM
  is the page's choice; HOME goes back to LIVE with the sound as edited.
- **Keep it in one press.** SAVE keeps the sound as one of sixteen USER sounds (`KEPT AS U01
  LAB 01`); EDIT + SAVE names it with the keys. PRESETS on LIVE plays them after the built-ins and
  DICE. An unsaved edit comes back at power-on.
- **Compare, undo, roll.** Tap EDIT for A/B; EDIT + LFO undoes (sixteen steps); EDIT + ARP varies
  the page, EDIT + SCL rolls the whole voice, and neither is ever silent. SAVE + a knob learns any
  card for MIDI.
- **DICE's settings on STEP.** Hold EDIT + SCL and turn K1 for the density (SPARSE to FULL) or K3
  for the scale (minor pentatonic to chromatic); let go to roll. Saved with the song.
- **The ARP helper picks its waveform** with PRESETS.
- **Readable TABLE and STEP:** their small text is at 2×.
- **Store health on STATUS,** and a background save that failed is retried and reported.

## Changed

- **ENV, LFO and FX on LIVE open LAB.** The chip model is now ALGORITHM on LIVE's TONE page (CC 25
  as before); the next effect algorithm is ALGORITHM on LAB's FX page.

## Fixed

- **Dense `.sid` players write on time:** a block of the audio renders in up to 23 parts instead of 15, so tunes such as
  Thomkat, Kill Me and The Last Ninja show LATE 0 on STATUS.
- **A sound edit no longer asks about the song** before SIDS plays a tune, and the sound stays as
  it was when the tune ends.
- **EDIT + SCL on STEP** is the same chord whichever finger lands first.

**Known untested:** long USB audio recordings at 48 kHz (an hour or more) have not been run on a
real FM-1; Felucca's resampler may meet a CPU erratum there
([felucca-bsp#16](https://github.com/hugelton/felucca-bsp/issues/16)). 44.1 kHz is not affected.
If a long 48 kHz recording resets the unit or clicks, please open an issue.

The full list is in [CHANGELOG.md](https://github.com/dsablic/sidou/blob/main/CHANGELOG.md).

## Install

Over USB, at your own risk; the official firmware is one install away. Use Felucca's installer:
`fm1_install.py sidou-1.0.0.fwsc`, from the stock firmware, a Felucca-family firmware or an
earlier SIDOU (it finds the FM-1 as "SIDOU FM-1"). Back to
stock: install M-VAVE's `FM-1.fwsc` the same way. Holding OCT- at power-on is a rescue.

**sidou-1.0.0.fwsc**, identity FM-1_964, SHA-256 `5a6b32bdf8a021a0c0ce9dbdebe5809fd339e526ed41c6bb9322ace051bb32f6`.
