# SIDOU 0.3.1

**An install over another firmware now boots straight into SIDOU.** Installed over Felucca, 0.3.0's
first boot went to the chip's USB boot screen (WL80UBOOT1.00) for about 45 seconds before SIDOU
started, and the installer reported "did not come back". Nothing was wrong with the install, but
it looked like it. 0.3.1 comes back in under a second.

- **Fixed:** the boot-loop guard no longer mistakes another firmware's leftovers in RAM for
  failed boots.
- **Fixed:** a store full of another firmware's data no longer holds up the boot; it is reclaimed
  in the background.
- **New on the website:** the [how-to videos](https://dsablic.github.io/sidou/videos.html) play in
  the browser.

Everything else is as in [0.3.0](https://github.com/dsablic/sidou/releases/tag/v0.3.0), whose
notes cover what SIDOU does, the songs to start with and the install. The full list is in
[CHANGELOG.md](https://github.com/dsablic/sidou/blob/main/CHANGELOG.md).

## Install

Over USB, at your own risk; the official firmware is one install away. Use Felucca's installer:
`fm1_install.py sidou-0.3.1.fwsc`, from the stock firmware, a Felucca-family firmware or an
earlier SIDOU (it finds the FM-1 as "SIDOU FM-1"). Back to stock: install M-VAVE's `FM-1.fwsc`
the same way. Holding OCT- at power-on is a rescue.
