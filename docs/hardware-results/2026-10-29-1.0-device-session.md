# 1.0 on a real FM-1, 2026-10-29

The 1.0.0 candidate (branch `rel100` c105ba49, FM-1_964, SHA-256 `5a6b32bd…`, `tools/preflash`
PASS 15/15) installed over v0.5.0 with Felucca 1.6.1's installer in 70 s; the unit came back as
`FM-1_964`.

## With the user

- **The first-run tour** (TURN K1, PRESS ENV into LAB's envelope, HOLD HOME FOR HELP): reads right.
- **LAB** (ENV, LFO and FX from LIVE, SELECT through the five pages): works.
- **The keep flow** (SAVE, `KEPT AS U01 LAB 01`, EDIT + SAVE to name, PRESETS to U01): works.
- The rest of the session's list (DICE's settings, the 2× text, STATUS, SIDS after a sound edit):
  "generally all seems to be working really well".
