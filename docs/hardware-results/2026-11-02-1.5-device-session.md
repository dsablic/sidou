# 1.5 on a real FM-1, 2026-11-02

Candidates 2 to 4, each through `tools/preflash` (PASS 15/15) and installed over the last in about
70 s: `c38096cf…` (candidate 2), `ac43801e…` (3), `81d00c7b…` (4, the release).

## With the user

- **Confirmations asked by an encoder:** SETTINGS' RESET needed ALGORITHM turned to arm. The user:
  "can we just use save like with everything else?", and the same for every other one. RESET,
  a foreign store's FORMAT, SONG's discard and delete question and SIDS' unsaved-song question are
  now SAVE, then SAVE AGAIN; no encoder confirms (candidate 3). On the device: work.
- **A faint hiss after every power-on**, until SETTINGS' RESET. Volume 0 silenced it; it was
  pitchless; USB unplugged changed nothing; a plain SAVE did not clear it; the EDIT light came on
  with it, which named it: an effect slot had an algorithm (LO-FI, whose B control is a noise
  floor). The boot's reload of the last song applied the song's own keys sound and effect slots
  over the settings' (since 0.2.0; the song had been saved with LO-FI on). Fixed: at power-on
  the last song leaves the keys as the settings kept them; SONG's LOAD still brings the song's
  (candidate 4). On the device: DIST stays OFF, no hiss; LOAD brings LO-FI.
- **LAB's song bridge** (REC sends, EDIT + REC replaces, ENV/LFO/FX on INSTR pull back): works.
- **The lift from a .sid** worked but "this is complicated… everything about it frankly" (solo,
  REC to arm, wait, a page, SAVE to import). Redesigned for 1.5.0: REC asks which voice, key 1-3
  takes its last note into LAB, SAVE keeps it (candidate 4). On the device: works.
- TRACKER's chords and BASS+DRUMS, the popups and paging on ORDER, TABLE and INSTR, and a quick
  pass over LIVE, LAB, STEP's DICE, a song and SIDS: work.
- **Live Link:** works; the page's encoders showed no turn from the computer keyboard (only from
  the mouse). Fixed on the site: the keyboard turns and presses the page's controls too, and
  turning the keyboard on lets go of focus. Works.
- The Library and the song editor (its preview included): work.
