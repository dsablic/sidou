The round trips exercise the store, SysEx and flash-write paths, which only the device runs, on
headroom part 2's smaller user stack (24,320 → 8,192 bytes): nothing failed and the unit kept
running.

**Found:** SysEx over USB moves about 0.9 KB/s up and 1.2 KB/s down (about 280 ms per 256-byte
DATA and its ACK up, 200 ms down). A 64 KB file takes over a minute each way. Worth a look
before Live Link and M3's `.sid` uploads lean on it ([TODO](../TODO.md)).

**The V15 round trip clears SIDOU's store** (V15 uses the same flash): the DIR after it listed
no files. The checklist says to save wanted songs first with SysEx GET; this run did not
(the unit held only test data).
