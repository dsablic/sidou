# Which text a player reads while playing. One rule a line: view | class | pattern.
#
#   view     a view's name as the firmware's view table is named (live, menu, chip, tracker,
#            status, scene, about, charset, midi, learn, title_card, boot) or * for every view
#   class    play   - read while playing (values, notes, names): must be big and contrasty
#            glance - read between sets, labels and help: contrast only
#            hint   - legends/help: contrast even when dim; never size
#            ignore - not judged (art, credits, the boot)
#   pattern  any | hex | note | value | words A,B,C | contains TEXT
#            hex: only two-hex-digit tokens (00, 04 05 0F)
#            note: starts like A-4 or C#3; value: a token of digits with an optional unit
#            (11.4K, +0, 125%); words: any of the names, case-insensitive; contains: a substring
#
# The first rule that matches (view, then pattern) decides; nothing matching is `glance`.
# The table reads text from the firmware's own grid, whatever its scale and place, so a
# redesign needs no edit here unless it adds a view or a name.
about   | ignore | any
charset | ignore | any
boot    | ignore | any
title_card | ignore | any
status  | glance | any
learn   | glance | any
tracker | glance | hex
# LAB: the page's name (2x) and ALGORITHM's choice (2x) are read while shaping. The cards' own names
# stay small by design (the knob row's labels) and fall to the rules below, so DELAY (the MOD card,
# the vibrato's delay) is judged like the effect of the same name.
lab     | play   | words OSC,ENVELOPE,FILTER,MOD,FX,LAB,INSTANT,AUTHENTIC,TRIANGLE,SAW,NOISE,LP,BP,HP,NOTCH,ARP
*       | hint   | words SELECT,ALGORITHM,ALG,HOME,MOVE,STEP,CHANGE,BACK,CANCEL,VOICE,MODEL,PROFILE,BPM,OL,K1
menu    | play   | any
# The menu's kin: SETTINGS' values and the SONG pages' actions, files and names are read as the
# menu's are.
settings | play  | any
song_menu | play | any
# The chord arpeggio's state on LIVE: read at arm's length while playing.
live    | play   | words ARP
*       | play   | note
*       | play   | value
*       | play   | words SAW LEAD,PWM BASS,SYNC LEAD,NOISE PERC,6581 R2,6581 R3,6581 R4AR,8580 R5,WORN 6581,USER,6581 BRIGHT,6581 DARK,6581 CLASSIC,8580 CLEAN,6581 GRITTY
*       | play   | words TAPE,OVERDRIVE,FUZZ,CRUSH,LO-FI,CHORUS,FLANGER,PHASER,TREMOLO,AUTO-PAN,WOW,DELAY,PING-PONG,REVERB,LUSH
