# The ergonomics harness's journeys: what a player does, step by step, in fm1-emu. Edit this
# file (or pass another with --journeys FILE) to add or change a journey; nothing else needs
# touching. The same table gives the "common tasks" for the effort and consistency checks.
#
#   journey ID | title [| tour] [| poweron]
#                              a journey, starting on LIVE after the boot, or at power-on
#                              with `poweron`; `tour` only visits screens (readability)
#   goal / prereq / skills / related   the recipe header, lines under `journey`
#                                       (skills and related: `;`-separated)
#   step ID | label | caption | actions [| flags]
#
#   caption   text for the manual and video subtitles, or - for none
#   actions   `;`-separated, run in order:
#               boot                      wait for the boot to end by itself
#               press BTN                 a button pressed and released
#               hold BTN MS               a button held
#               turn ENC N                an encoder, N detents (negative: counter-clockwise)
#               holdturn BTN ENC N        a button held while an encoder turns (two hands)
#               holdkey BTN NOTE          a button held while a note key is pressed (GLO + key)
#               holdpress BTN BTN         a button held while another button is pressed (EDIT + SCL)
#               note NOTE [NOTE..] MS     keys held together (F3..G5, C4 = middle C)
#               down NOTE / up NOTE       a key held down / let go (to play while turning)
#               select-item TEXT          the menu's (or SETTINGS') selection onto the line starting with TEXT, read from
#                                         the firmware's cursor (forward, then back: not found, or a
#                                         `view V` that is not reached, is "navigation failed")
#               midi HEX..  cc N V  pc N  bytes into the TRS jack
#               pot V                     the MASTER pot, 0..1023
#               clock BPM MS [start]      MIDI clock for MS ms, after a start if given
#               wait MS                   do nothing (counts as forced waiting)
#               powercycle                switch off and on again over the same flash
#   flags     `;`-separated:
#               setup                     set-up step: two hands allowed (not JOUR.hands)
#               view V | sound | silent | change | popup | toast | text T | big T | recalled
#                                         (big T: the text at 2x or larger, readable at arm's length)
#                                         what must hold when the step is done (else a dead end)
#               needs F                   a feature (theme undo help order_view instr_view
#                                         pattern_edit new_song song_save); missing: the step is
#                                         recorded "not yet possible" instead of failing
#               clip MS                   keep the audio around the step (+ MS after) as a clip
#               probe                     afterwards press a note: can one still sound?
#               task NAME                 the step belongs to a common task (consecutive steps
#                                         with one NAME are one task: its actions, menu levels
#                                         and frames are scored against the effort limit)
#               milestone first_loop      the step is where the first loop plays
#               destructive               the step may overwrite work: is it confirmed?
#               remember                  keep the parameters (for `recalled` later)
#               defaults                  judge the audio as a musical default
#               do TEXT                   the control in panel terms (else made from the actions)
#               value NAME MIN MAX | absent TEXT | brighter | darker | louder | quieter
#               level MIN MAX         more outcomes: a parameter in a range, text absent, the sound
#                                     against the 400 ms before the step, the last 400 ms's dBFS
# View names are the firmware's view tables: live menu settings chip tracker status scene about
# charset midi learn.

journey jam | Pick up and jam | poweron
  goal Go from switched off to a played, shaped sound.
  prereq The FM-1 running SIDOU, just switched on.
  skills playing; shaping with K1-K4; presets; volume; octave
  related sketch; perform; explore
  step note-at-power-on | Press a key straight after power-on | Press a key: it sounds | note A4 600 | sound; clip 400; probe; milestone first_sound; defaults
  step boot-settles | Let the boot end | - | wait 2500 | view live
  step chord | Play a chord | Play a chord | note C4 E4 G4 700 | sound; clip 300
  step shape-cutoff | Turn K1 while holding a note | Turn K1 to open and close the filter | down A3; turn K1 -24; turn K1 24; up A3 | change; clip 300
  step shape-resonance | Turn K2 | Turn K2 for resonance | down A3; turn K2 8; turn K2 -8; up A3 | change; clip 300
  step shape-pulse | Turn K3 | Turn K3 for the sound's own control | down A3; turn K3 6; turn K3 -6; up A3 | change; remember; clip 300
  step next-preset | Turn PRESETS to the next sound | Turn PRESETS to change the sound | turn PRESETS 1; note A3 600 | sound; clip 300; task change preset; destructive; defaults
  step back-preset | Back to your sound | Turning back brings your edits back | turn PRESETS -1 | recalled
  step master | Turn MASTER down | MASTER sets the volume | down A3; pot 300; pot 1000; up A3 | popup; clip 300
  step octave | Octave up | OCT+ steps the octave | press OCT+ | toast; task change octave

journey perform | Perform
  goal Play along with a MIDI clock, switch sounds, mute and solo live.
  prereq On LIVE after the boot; a sequencer on the TRS jack.
  skills MIDI clock; program change; GLO mutes and solos; MIDI learn
  related jam; sketch

  step panel-preset | Switch sound from the panel | PRESETS picks the sound | turn PRESETS -2 | text SAW LEAD; task change preset
  step mute-voice-2 | Latch GLO and press key 2 | Double-tap GLO, then key 2 | press GLO; press GLO; note F#3 200 | quieter; task mute voice 2; probe
  step unmute-voice-2 | Let voice 2 sound again | Again to unmute | note F#3 200 | louder; task unmute voice 2
  step solo-voice-1 | Solo voice 1 | Press key 4 | note G#3 200 | quieter; task solo voice 1; probe
  step unsolo-voice-1 | Unsolo voice 1 | Again to unsolo | note G#3 200 | louder; task unsolo voice 1
  step unlatch | Let GLO go | A tap on GLO ends the layer | press GLO | -
  step learn-cc | Learn a CC for K1 | Hold SAVE and turn K1, then move a controller | holdturn SAVE K1 1; cc 21 64 | text LEARNED; task learn a CC; setup
  step stop-clock | The clock stops | - | wait 800 | -
