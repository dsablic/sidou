Scene Arcade

Tiny looping scenes for the FM-1's 240×240 screen, each an original homage to a kind of 8-bit game. Nobody plays them: a built-in three-voice pattern at 124 BPM drives every move. The late-era set borrows the tricks of 1988–93 games (parallax bands, raster-split skies, colour cycling, shaded multicolour sprites), and every frame is measured the way the device pays for it, in 8×8 tiles sent over SPI.

      Ground rules

      • All characters, sprites, titles and layouts are new. Each caption names only the genre that inspired it; no game names, logos, sprites or level maps are used.
      • Everything is drawn in the 16 Pepto C64 colours. Early-era sprites are hand-placed pixel rows; late-era sprites are posed skeletons painted with 4-step colour ramps, rim lighting, ordered dither and a black outline, at the C64's double-wide multicolour pixel.
      • Software parallax pays per band, the way C64 games did. A shift costs the same whether it moves 1 pixel or 8, because every tile with detail in it changes either way; so the far band moves in big steps on rare frames, the middle band every 2nd frame, and only the ground moves every frame. The updates are staggered so two heavy bands never land on the same frame, and the sky never changes except while a new colour scheme wipes down one tile row per frame.
      • Cheap texture: dithered horizontal stripes look the same after a shift of 4 pixels, so the ground scrolls in 4-pixel steps and only its top edge is re-sent. Colour cycling is kept to a few small spots, because every cycled tile is re-sent.
      • Keys: ← and → change vignette, Space plays and pauses.
