# Prototypes

Self-contained HTML pages made for SIDOU while designing its look and feel.
Open them in a browser; everything they draw is generated by their own code.

- `sidou-screens.html`: the 240×240 screen prototype — boot, LIVE, STEP,
  TRACKER, SCENE pieces, menu and About, with each screen's SPI cost. M2d's
  STEP and TRACKER views start from it.
- `sidou-vignettes.html`: the Scene Arcade — music-driven vignettes for the
  SCENE view, early and late era, each measured against the 225-tile budget.
  M2f's RED MOON RITE is drawn by its code.

Every character, sprite and layout in them is original; captions name only
the genres that inspired them.
