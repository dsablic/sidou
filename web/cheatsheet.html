Cheat sheet · SIDOU 0.4.0

Play it in the browser · Videos · Songs for your FM-1 · Songs to MIDI · Source ·

SIDOU turns the M-VAVE FM-1 into a C64 SID instrument: two emulated SID chips (6581 or 8580) played from the keys and over MIDI, three effect slots, and GoatTracker 2 songs made on STEP and TRACKER. Hold HOME on any screen for its help card: what each control does there, right now. E+ means EDIT held; + means held together.

The panel on LIVE (the screen at power-on)

Note keysplay the chip, F3–G5 at the current octave (always velocity 127)
OCT− / OCT+octave −3…+3; their LEDs show the direction
FXchip model 6581 / 8580 (lit for the 8580)
K1 · K2cutoff · resonance
K3the sound's own control: PULSE (pulse width), RATIO (SYNC LEAD's sync ratio) or DECAY
K4release, 0–15
PRESETS (big knob)the sound: SAW LEAD, PWM BASS, SYNC LEAD, NOISE PERC, DICE
MASTERvolume of everything (keys, songs, UI sounds)
SELECTpages the knob row: TONE, DIST, MOD, FX
ALGORITHMon TONE the chip profile; on a slot's page that slot's algorithm
E+ K1–K4the selected effect slot's Amount, A, B, Mix (any view)
SCL · ENVnext effect slot · its next algorithm (any view)
ARPchord arpeggio on/off; held + K1–K3 its rate, order, span
GLO + key 1–3 / 4–6mute / solo song voice 1–3 (any view)
SEQ · PLAY · RECsong views · play/stop the song · record mode
HOME · SAVEtap: the menu · hold: help card · SAVE: saves the settings now

Getting around

tap HOMEthe menu from LIVE; back one view anywhere else
hold HOME (0.6 s)help card of this view in its current state; SELECT turns a 2-page card; any other control closes it
Menu: SELECTmove: CHIP, TRACKER, SCENE, SONG, PRE, OCTAVE, SETTINGS, STATUS, MIDI, CHARSET, ABOUT
Menu: SAVEOK: opens the highlighted item (ALGORITHM clockwise does too)
Menu: ALGORITHMon PRE / OCTAVE changes the value
STATUS: SELECTturns its 3 pages: knobs (6502 with a tune), chip + preset + notes, effects
SEQopens the song view used last; again: STEP → TRACKER → ORDER → INSTR → TABLE → STEP
Any controlskips the boot or a title card (a note skips and plays)

Lights

  • Lit = active now, dim = set. ARP dim while on, flashes on its steps · PLAY pulses on the beat · REC dim armed, blinking count-in, lit recording · SAVE blinks while a question waits · GLO lit while latched.
  • GLO held/latched: keys 1–3 lit while the voice sounds (dark muted), 4–6 blink for a solo. On STEP the 16 step keys show the page (lit a note, dim empty).

Playing

PRESETS clockwisenext preset; past NOISE PERC, DICE rolls a new random sound each turn (DICE 07); back and forth returns the last roll
E+ PRESETSthis preset back to factory (DICE: back to its base)
SAW LEAD** = edited; each preset keeps its edits while you play another (not over a power cycle, except the current one)
tap ARPchord arpeggio: hold a chord, one voice steps through it (badge ARP 3F UP 1OCT)
ARP + K1rate: 1F 2F 3F 4F 6F 8F (frames a note), /32 /16 /8 of MIDI clock
ARP + K2 · K3order UP DN UD AS (as played) · span 1 or 2 octaves
FX6581 ↔ 8580 (back to the last 6581 profile)
Two chipsno song: keys on chip A; a song playing: keys on chip B on top (KEYS:B). SETTINGS KEYS A keeps them on A
CHIP SPREADSETTINGS → SPREAD OFF…100 %: chip A left, chip B right, while both sound
GLO tapped twicelatches the mute/solo layer (GLO LATCHED); tap GLO to end

ARP settings are per preset and off at power-on.

Sound

TONE pageK1 cutoff · K2 reso · K3 own control · K4 release
DIST / MOD / FX pageK1–K4 that slot's Amount · A · B · Mix (named for the algorithm, e.g. DRIVE TONE BIAS MIX)
ALGORITHM on TONEprofile: R2 (bright), R3 (dark), R4AR (classic, power-on), R5 (8580, clean), WORN (gritty)
SCL / E+ K / ENVpick a slot / turn it / step its algorithm; a new algorithm starts from a setting you hear at once

CHIP view (menu → CHIP)

SELECTfocus: A/B tabs, CHIP, DIST, MOD, FX, EXPERT
ALGORITHMtab · profile (built-ins, then USER 1–8) · slot algorithm · EXPERT page 1–4
K1–K4 on CHIPcharacter: AGE, DAC, THUMP (note thump), BLEED
E+ ALGORITHM, SAVEpick USER 1–8 (SAVE TO USER 3), SAVE stores the profile (asks before overwriting)

ENV = next algorithm, LFO = clear (in STEP and TRACKER), GLO = mutes and solos. LFO does nothing on LIVE.

STEP (song as a drum machine)

Step key 1–16toggle a note on that step of the lane (no REC needed)
SELECT · ALGORITHMlane V1 V2 V3 · page of 16 steps
PRESETSthe lane's instrument, by name (03 KICK)
ARPthe lane's gate: STACCATO / LEGATO
step held + K1 · K2 · K3LOCK cutoff · resonance · pulse width on that step
step held + K4waveform SET: OFF TRI SAW PULSE NOISE
step held + E+ K1–K4character LOCKs: age, DAC, thump, bleed
step held + ALGORITHMCHANCE 100 %…0 in steps of 5
step held + PRESETSthat step's note (and the lane's next notes)
step held + LFOclear the step's locks, chance and SET
E+ SCLDICE: a new pattern for the lane (NEW PATTERN)
E+ ARPMUTATE: two small changes (MUTATED)
E+ LFOone undo (again: redo)
Keys 17+audition

A NEW song's instruments

  • 01 lead · 02 bass · 03–0A SID drum kit: KICK, SNARE, CL HAT, OP HAT, CLAP, TOM LO, TOM HI, RIM
  • 0B–0E digi drums (4-bit samples): DG KICK, DG SNARE, DG CLAP, DG HAT. GoatTracker plays chip-kit copies instead.
  • 3 voices, 64-row patterns, tempo 6. DICE and MUTATE use the minor pentatonic on the lane's note; a drum lane keeps its note.

NOW PLAYING ALGthe song before / after, from its init

Saving & loading

SAVE in a song viewsaves the song (unnamed: SAVE AS). Songs are not autosaved.
SAVE elsewheresettings now (SAVED); they also save themselves 5 s after a change
Menu → SONGLOAD (built-in SIDOU LOOP first) · NEW · SAVE AS (16 letters: SELECT cursor, ALG letter) · DELETE (asks)
Unsaved songLOAD and NEW ask before discarding it
Power-onthe last song loads, stopped

SETTINGS (menu → SETTINGS, ALGORITHM changes)

KEYSAUTO (chip B during a song) / A
SOUNDSUI sounds OFF / ON
ROWSTRACKER rows: BAR / SCROLL
CARDStitle cards OFF / ONCE / ALWAYS
STOREfree space (193K); FOREIGN / NEWER: ALG clockwise arms, SAVE formats: wipes all data
THEMEHIGH (contrast) / C64
RECrecord quantise (not saved)
SPREADOFF, 10 %…100 %
RESETALG clockwise asks (RESET?), SAVE resets every preset and setting. Keeps songs, USER profiles, MIDI learn

Only STORE and RESET ask first; HOME or moving away cancels. The rest save themselves.

MIDI

Notesevery channel (OMNI) on TRS and USB; menu → MIDI sets MODE (LIVE, MULTI, WHOLE A/B, OMNI), CHANNEL, CLOCK, CLOCK OUT… (not saved)
Program change0–3 the presets (bank 0); bank 1 (CC 0=0, 32=1) loads song n in name order; bank 2 picks the profile 0–12
Main CCs74 cutoff · 71 reso · 1 pulse width · 7 volume · 73/75/79/72 A D S R · 25 chip model · 85 profile · 86 87 89 90 age DAC thump bleed · 117 spread
More CCs20 wave · 21 ring · 22 sync · 23 filter mode · 24 routing · 26 envelope mode · 27–30 arp on/rate/order/span · 76–78 vibrato · 120/123 all notes off
Effect slotsDist 102–106 · Mod 107–111 · FX 112–116 (algorithm, Amount, A, B, Mix)
SAVE + turn a knobMIDI learn: send a CC to bind it (LEARNED CC 21 → CUTOFF); SAVE again in the frame forgets it; HOME cancels
MIDI outUSB only, channel 1: the panel's knobs, MASTER, FX and slots as CCs, PRESETS as a program change; MIDI input is never echoed
Clockthe song follows MIDI clock and start/stop (CLOCK AUTO); CLOCK OUT ON sends it over USB

Every parameter also has an NRPN: the full map is midi.md.

Power-on

any buttonskips the boot animation (a note skips and plays)
hold HOMEplays the full boot sequence
hold OCT− alone (~1 s)recovery: the chip's ROM boot mode, screen black, USB WL82 UBOOT1.00; restore a package with tools/fm1-unbrick-mac or MvaveFM1Unbricker. Switch off and on to leave it, nothing written
crash at every bootafter two failed boots the next one goes to ROM boot mode by itself

Before switching off: let the settings save finish (5 s after a change), or press SAVE and wait for SAVED.
